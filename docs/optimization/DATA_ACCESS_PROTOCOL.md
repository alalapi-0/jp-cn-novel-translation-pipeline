# 优化实验的数据访问协议

读者：后续开发、评价和回归 Agent。修改触发：集合身份、来源适配器或数据放行规则改变时同步更新。本页解释访问边界；唯一任务状态仍是 `governance/round_state.yaml` 的 `codex_governance`，不从本页选择下一轮。

## 冻结输入和抽样

`scripts/build_optimization_split.py` 消费已登记、固定 SHA256 的 `versions.json` 和位置对齐元数据。构建时只打开 `source_original` 快照；旧译、用户修改、反馈、知识和 TM 正文不参与选样。原始 3,553 路径分母与新增 12,010 路径同时保留，609 个原文章节全部分配。

连续十章为一组，遇到缺章或方向变化就结束该组。每五组作为一个时间区段，以固定种子的 SHA256 排序选出一个完整留出组，最后不足五组仍选一组。开发/留出两边分别固定最多八个代表性随机章节，另按源文线索选每类最多两个难点候选。上下文单位是完整章节组，相邻原文可用于理解；不能把相邻句随机分到两边。

这是以连续章节代替叙事区段的可复现分组，尚未人工核实情节弧边界。跨组可能共享故事背景，不能据此假定统计独立。九类现象全部保存覆盖状态和缺口：代词、引号、敬称、否定条件、片假名、拟声/文化等只作候选线索；伏笔、人物声音及语义遗漏没有靠关键词获得验证。后续评价器校准仍需源文和上下文证据。一个作品不能支持跨作品结论。

私有产物为 `workspace/tooling/optimization/P1.R02.T02/frozen-split/split.json` 和摘要。唯一状态保存其 SHA256。改变种子、分组、输入或评价条件时保留旧身份及曝光历史，不能覆盖旧分母或把重试称为首次保留测试。

## 开发数据放行

后续开发实验使用 `DevelopmentReader(root, manifest, expected_sha256)`，由当前状态读取并固定 manifest 身份。接口如下：

- `source_context((direction, chapter_id, source_revision))`：可取开发或留出章的固定原文。旧版本、未知身份拒绝。
- `target(record_id)`：由固定对齐记录自行推导来源，核对唯一精确源文位置、开发分区、登记的快照/JSON 指针、源字段和目标字段 SHA256，才返回一个旧译字段。返回结果明确为待核验旧译，不携带旧 human/approved 标签。
- `feedback(...)`：拒绝。裁决、反馈、知识、TM 和旧导出均不能通过未知血缘进入开发。后续任务须另建有证据的适配器，推导全部依赖来源；任一留出或未知依赖都拒绝，不能由调用者自己填写“开发章”来放行。

留出目标请求在读取目标快照前拒绝。来自同一旧 JSON 的开发字段和留出字段可能混存：读取器内部会解析登记容器，只向调用方返回经核对的单个开发字段，不提供整个容器接口。不确定定位、来源版本不明、失效 manifest/快照、错误目标指针都拒绝。合法空旧译仍可被记录为空，不据此伪造质量通过。

这限制的是实验的数据放行路径，不是阻止文件所有者直接访问磁盘的 OS 沙箱。现有生产 runner 尚未被声称采用此接口；P2 接线时必须保持这一边界。隔离工程测试仍走 `scripts/isolated_checks.py`，不读取真实集合。

P3 的 `scripts/audit_optimization_knowledge.py` 是单独的私有结构审计适配器。准备阶段只读取固定盘点与 split 元数据，不打开知识或原文快照。只有精确候选、计划、输出路径和时限获得独立审查及治理批准后，才能在封闭的确定性遍历中解析明确列出的冻结容器；混存的 TM/旧译或风格字段不得向模型释放。记录仅输出身份、类别、出处状态和保留为未核的处置，不输出实体名、命题、译文、风格或原文引句。它不提供知识正文消费接口，不解除 DevelopmentReader 对反馈/保留目标的拒绝，也不证明任何实际知识正确。

实际来源核验可使用 `assets.source_knowledge` 的源文独立候选路径：先经精确授权读取一个固定开发原文章节，提取和独立复核只看该原文及本次新候选。旧知识保持封闭，不能用来调生成或评价。两次实际原生历史结束后，获准的确定性程序才可内部比较新候选与两份固定旧配置的名字映射；其输出仅为不可提权的对应诊断。它不推导旧资料缺失的上游血缘，不放行旧正文、保留目标或私人风格资料，不改变原始盘点和未核状态。任何模型调用仍须经过既有 whole-source 预算预留、准入、实际回执和进程收束检查。

## 留出评估与曝光

开发读取器没有解封开关，也不接受 `evaluation=True`、`allow=True` 等参数改变权限。P5 只有在候选、Prompt、阈值、知识、模型条件及评价协议冻结后，才由独立的评价入口打开留出目标/裁决/反馈。该入口尚未实现，不能把当前冻结 manifest 当作已完成留出回归。

失败或曝光必须保留：返回开发集修复，原结果仍是失败/已曝光；后续使用相同留出集时注明这一事实。必要原文上下文可见，目标和反馈不得用来调 Prompt、阈值或策略。没有可靠参考时使用源文审查，不把旧译自动当真值。

## 证据

合成测试覆盖整组互斥、分母、固定种子、插入错误分区、未知/旧源版本、跨分区依赖、同容器留出请求、单字段放行、旧批准不提权、反馈拒绝，以及 manifest/对齐/快照变更。真实构建另保存源文专用读取计数和实际留出请求拒绝回执。测试和这些回执证明访问规则与分组，不能证明文学质量或语义覆盖。

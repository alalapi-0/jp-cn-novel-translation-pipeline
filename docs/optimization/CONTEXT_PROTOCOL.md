# 翻译请求的前文与叙事上下文

读者：Prompt、draft runner 和后续知识适配器维护者。变更触发：上下文来源、时间范围、可信等级或指纹规则改变时。本页描述工程接口；唯一任务状态仍为 `governance/round_state.yaml`，本页不授予数据访问或内容批准权限。

`SourceContextCatalog` 从本次选定的不可变原文建立有序目录。默认邻近窗口仍为前三段、最多 1200 个码点，可显式设置为零。这是尚未证明最优的简单基线。当前批头不能充当前文，目录外、重复、乱序或改稿后的锚点拒绝。选定章节之前未载入的章节不被假装成已读上下文。

`NarrativeContextCatalog` 是可选的内存上下文接口，两条 draft stage 入口均可传入；默认目录为空。不自动读知识、TM、反馈或任何旧目标文件。真实资料仍须遵循 `DATA_ACCESS_PROTOCOL.md` 的固定来源适配器；本接口不是该适配器，也不解封留出目标。

事实项只接受指定段的完整 SHA256、码点范围及完全相等的原文引用，不接受脱离原文的自由推断。核验的只是出处；`semantic_truth=not_verified` 明确保留原文可能包含谎言、误会和不可靠叙述者。有效期使用所选原文的文本顺序，不声称已经推断故事内部时间、闪回或隐藏真相。起点不得早于证据所在段，证据必须严格早于被服务的段；终点不包含在有效期内。相同 slot 的相交说话人范围不得重叠，要求调用方先明确范围。说话人、关系 slot 及有效期均为调用者标注，必须由后续资料核验确认；没有说话人标注时不匹配人物专属条目。没有依据时保持未知，不自动全书统一人物关系。

上下文按每个当前 segment_id 单独分配，因此同一批中前后段可以具有不同关系。原文事实引用只能帮助理解，不能把已知情节补入当前译文。不能由这项工程过滤推导出模型绝不剧透的语义结论。

前译必须绑定相同原文段版本和非空目标，且严格位于整个当前批之前。它带目标 SHA256、项目和既有 Workbench review identity。复用既有只读 `review_decision_summary`：当前精确源/译身份下 Agent/PSH 代理已接受者标为 `higher_nonhuman_accepted`；缺证据、旧 approved 标签、机器建议、未知或改过译文的旧审查均为 `low_unverified`。两者均不是真人批准，不自动成为真值或正式稿；高低仅为上下文使用者保留证据差异。调用方必须是已获授权的本地服务，保存的 JSON 标签不构成外部身份认证。构建后冻结原始 review 输入，后续原对象修改不能偷偷改变目录。

每批事实和前译合计最多 8 项引用、3 项前译、2400 个正文码点，参数可缩小或设零；按最近证据选择，超出窗口的整条不发送，不截断后冒充完整证据。上限在整个批次累计，元数据和 JSON 结构开销另计。未核验旧资产、glossary_hits 和 prev_tail_summary 原文不进入 draft Prompt，只记录被扣留提示的摘要。draft 入口收到旧资产路径时在读取文件或构造 provider 前拒绝；自动 configs/TM 装配通路已停止。资产生成、历史文件和旧 refine 路由未在本单元迁移，不能宣称全应用的所有知识消费者都已遵守这些规则。

目录、策略、说话人标注、事实范围、原文、目标和审查证据进入稳定指纹；每个实际 provider 请求携带本批上下文指纹。相同 run 恢复时目录或策略改变即拒绝，保留原候选和预算。Prompt 也校验本批 ID 与当前原文 SHA256，不能给同 ID 的新原文套用旧上下文。

合成测试覆盖跨章/跨批、未来事实倒填、关系变化、说话人未知、过期/重叠、范围及摘要错误、前译可信等级、旧标签和改稿、总窗口、实际请求和恢复。真实开发区段的窗口消融与语义收益尚未验收；没有可靠收益前默认使用邻近原文，不增加上下文或自动采用任何候选。后续 P3 的事实抽取、核验、撤回及真实 TM 适配仍待完成。

# 项目愿景：中日文小说互译生产流水线

## 项目一句话定位

本项目旨在构建一个面向长篇小说与轻小说的中日文互译生产流水线，通过术语库、角色设定、世界观设定、embedding 检索、向量数据库、批量翻译、一致性校对、唯一最终译文导出和前端审核工作台，提升整本小说翻译的一致性、可控性和可复查性。

## 当前阶段

当前仓库已经进入 `final_ready` v2 治理阶段：本书翻译与一致性校对已收口，自动化主线不再包含润色 / R-MR / production_candidate。后续工作重点是把同一套“翻译 → 一致性校对 → baseline lock → singleton final export”协议复用于新作品，并让 Workbench 与调度器全部显示 v2 状态。

## 当前可用 vs 未来能力

| 领域 | 当前可用（Round 57） | 未来目标 |
|---|---|---|
| 生成入口 | API Mode / Agent Quota Mode 双路径协议、dry-run/mock 安全路径 | 章节级批处理、后台任务编排、可视化调度 |
| 审核与导出 | 对照审核、审核状态持久化、manifest 导出、singleton final export | 细粒度审核协作、发布审批流、更多导出制品 |
| 质量检查 | 一致性校对、quality-review API 与页面展示，支持 fallback 数据源标识 | 用户修改稿同步、长期质量趋势与规则学习 |
| 运行安全 | 成本守卫、脱敏错误映射、敏感信息不落盘 | 多 provider 智能熔断、故障自愈与SLO监控 |

## 长期目标

1. 支持日文小说翻译为中文。
2. 支持中文小说翻译为日文。
3. 支持单本小说项目管理。
4. 支持多项目管理。
5. 支持术语库。
6. 支持角色设定库。
7. 支持世界观设定库。
8. 支持翻译记忆。
9. 支持 embedding 与向量数据库。
10. 支持按章节、按卷、按批次翻译。
11. 支持翻译中间态与一致性校对分离。
12. 支持 API 翻译与 Agent 额度翻译共用同一产物协议。
13. 支持翻译一致性检查。
14. 支持前端操作页面。
15. 支持用户手动审核、修正、锁定术语。
16. 支持本地运行优先，未来可扩展到服务端。
17. 支持多模型和多 API provider 可替换接入。
18. 支持成本记录、预算保护和 dry-run。
19. 支持原文译文对照审核。
20. 支持后续连续推进轮机制。

## 非目标

1. 本项目不是盗版发布工具。
2. 本项目不鼓励未经授权公开发布受版权保护的译文。
3. 本项目不是单纯机翻脚本。
4. 本项目不是只为一次性翻译一本书。
5. 本项目不是模型供应商绑定项目。
6. 本项目不应把 API Key、原文版权内容、用户隐私内容提交到公开仓库。
7. 本项目不应在治理轮中启动真实小说翻译。
8. 本项目不应把 embedding 或向量库当作替代术语表和人工审核的工具。
9. 本项目不应默认公开发布输出结果。

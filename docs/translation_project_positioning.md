# 项目定位

## 项目定位

本项目是一个面向轻小说、游戏文本、异世界题材的 **日文 → 中文**（以及未来的 **中文 → 日文**）结构化翻译工作流仓库。它提供了从原文输入、术语库维护、初稿生成、润色、质量检查、双语对照到最终发布的完整管线，旨在帮助个人翻译者或小型协作团队实现 **高质量、可重复、可扩展** 的翻译过程。

## 当前项目不做的事情

- **不直接分发有版权风险的原文**：原文文件仅用于个人学习与翻译，不会公开发布。
- **不把 API Key 写入仓库**：所有密钥均通过环境变量提供，`.env.example` 仅包含占位符。
- **不自动覆盖人工译文**：任何生成的译文只能写入 `output_cn/experiments/`，正式译文目录仅在人工审校后手动复制。
- **不把机器翻译结果直接当作最终稿**：机器输出仅作为草稿（draft），后续必须经过人工润色与一致性检查。
- **不使用 Embedding 直接翻译正文**：Embedding 用于检索记忆，而非直接生成译文。
- **不让模型绕过术语表随意发挥**：术语统一、人物称呼必须遵循 `notes/glossary.md` 与 `notes/character_names.md`。

## 目标用户

- **个人翻译者**：想要系统化管理轻小说翻译全过程的个人用户。
- **轻小说翻译项目**：小团队协作、章节划分、进度管理等需求。
- **游戏文本翻译项目**：需要统一术语、角色称呼、对话风格的游戏本地化。
- **中日双向翻译练习项目**：练习中译日、日译中的语言对比与模型调优。
- **AI 辅助汉化/日文化工作流实验项目**：探索多模型协同、Embedding 检索等前沿技术的实验平台。
